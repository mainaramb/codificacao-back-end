#  Codificação Back-End

Este repositório reúne códigos, exercícios e projetos desenvolvidos ao longo dos meus estudos de **Desenvolvimento Back-End**, utilizando o ecossistema JavaScript.

---

##  Objetivos

- **Compreender a Arquitetura Back-End:** Entender o fluxo de requisição e resposta na Web entre cliente e servidor.
- **Construção de APIs RESTful:** Criar rotas, manipular dados e estruturar serviços robustos e escaláveis.
- **Domínio de Ferramentas:** Praticar o controle de versão, gerenciamento de dependências e execução de scripts em ambiente de desenvolvimento.
- **Consolidação do Aprendizado:** Manter um histórico organizado dos conteúdos e módulos estudados para consulta e portfólio.

---

##  Conteúdo

O repositório aborda os seguintes tópicos e conceitos de estudo:

### 🔹 Fundamentos do Node.js
- Event Loop e assincronismo (`async/await`, Promises).
- Módulos nativos (`fs`, `http`, `path`).
- Criação e execução de scripts server-side.

### 🔹 Desenvolvimento Web com Express
- Roteamento e métodos HTTP (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`).
- Tratamento de parâmetros de requisição (`req.params`, `req.query`, `req.body`).
- Uso e criação de Middlewares (validação, autenticação, logs).
- Respostas padronizadas em formato JSON e códigos de status HTTP (200, 201, 400, 404, 500).

### 🔹 Gestão de Pacotes e Projetos
- Inicialização de projetos e arquivos de configuração (`package.json`).
- Instalação e gerenciamento de bibliotecas de terceiros.
- Organização da estrutura de pastas e boas práticas de código.

---

##  Tecnologias

- **JavaScript:** Linguagem principal para desenvolvimento do código no lado do servidor.
- **Node.js:** Ambiente de execução JavaScript no servidor.
- **Express:** Framework web mínimo e flexível para criação de APIs e rotas HTTP.

---

##  Ferramentas

- **Node.js:** Runtime para execução do código JavaScript localmente.
- **NPM (Node Package Manager):** Gerenciador de pacotes para instalação de dependências e execução de scripts.
- **Express:** Framework para estruturação rápida de servidores e rotas.
- **Git:** Sistema de controle de versão utilizado para rastrear alterações no código.
- **GitHub:** Plataforma para hospedagem do código-fonte e gerenciamento do repositório remoto.
